# Amit Choudhary — Portfolio

A single-page Next.js portfolio built from Amit's verified résumé and original project screenshots.

## Design direction

- Uses the visual system of `crypto_algo_trading_website`: obsidian surfaces, emerald accents, mono labels, subtle grid/noise texture and elevated dark cards.
- Uses the supplied reference portfolio only for information architecture and UX: compact anchor navigation, text-first hero, career metrics, scannable sections and responsive cards.
- Keeps the content and branding specific to Amit; no reference-site content is reused.
- Uses original project screenshots where available and styled image placeholders for screenshots that will be supplied later.
- Omits placeholder phone, email, LinkedIn and GitHub details until verified values are available.

## Stack

- Next.js App Router
- React
- Plain JavaScript and global CSS
- Static export to `out/`

## Run locally

```bash
npm run dev
```

## Production build

```bash
npm run build
```
